Golden set format — one JSON file per document.

Each file must contain:

{
  "source_type": "biorxiv" | "pubmed" | "clinicaltrials" | "edgar" | "epo_ops",
  "external_id": "<source-specific ID>",
  "source_url": "<full URL to the original document>",
  "published_date": "<ISO 8601 datetime with timezone, e.g. 2024-06-15T12:00:00Z>",
  "raw_content": "<title + abstract or equivalent text, as fetched by the connector>",
  "labels": {
    "is_signal": true | false,
    "gene_targets": ["HGNC symbol", ...],
    "mechanisms": ["base editing", ...],
    "companies_mentioned": ["Company Name", ...],
    "directionality": "positive" | "negative" | "neutral",
    "prefilter_should_pass": true | false,
    "event_type": "trial_readout" | ... (optional; see prompts/extraction/v1.1.txt),
    "primary_company": "Company Name" | null (optional),
    "program_identifiers": ["SRP-9001", ...] (optional),
    "trial_ids": ["NCT05096221", ...] (optional)
  }
}

The optional labels are scored only on signal documents that carry them.

Coverage target: 20-30 docs, all 5 source types represented, both is_signal classes,
and both prefilter outcomes. Filename convention: <source_type>-<external_id>.json

Run the scoring script:
  uv run python scripts/score_extraction.py
